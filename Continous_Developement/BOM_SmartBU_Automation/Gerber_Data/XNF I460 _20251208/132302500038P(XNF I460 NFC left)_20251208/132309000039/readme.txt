GERBER FILE FORMAT

*.**D = Gerber D - 3.4 abs,imp,leading (all layers viewed from component side)
	  No embedded apertures - aperture file (APERTURE.GAP) required.
*.**X = Gerber X - 3.4 abs,imp,leading (all layers viewed from component side)
	  Embedded apertures - aperture file (APERTURE.GAP) not required.

PCB Fabrication Files:-	
	*.CC*			-	  Component side copper
	*.SC*			-     	  Solder side copper
	*.I1*			-	  Inner Layer Copper 1
	*.I2*			-	  Inner Layer Copper 2  etc.
	*.OU*			-	  Single PCB outline
	*.CS*			-	  Component side silkscreen
	*.SS*			-     	  Solder side silkscreen
	*.CR*			-	  Component side solder resist mask
	*.SR*			-     	  Solder side solder resist mask
	*.CL*			-	  Component side solder peelable resist 
	*.SL*			-     	  Solder side solder peelable resist
	*.CM*			-	  Component side peelable masking
	*.SM			-	  Solder side peelable masking
	*.FD*			-     	  Drill detail
	*.PD*			-	  Panel drawing
	*.CO*			-	  Solder side coating 

PCB Assembly Files:-	
	*.CP*			-	  Component side solder paste 
	*.SP*			-     	  Solder side solder paste 
	*.CG*			-	  Component side glue dot 
	*.SG*			-     	  Solder side glue dot
	*.CA*			-	  Component side Assembly Drawing
	*.SA*			-     	  Solder side Assembly Drawing
	*.CT*			-	  Component side solder paste stencil drawing
	*.ST*			-     	  Solder side solder paste stencil drawing 
	*.sea*			-	  sealing
	 
NC Drill 
      	*.NCD			-      	  NC drill file
      	*.DRL			-      	  NC drill file
      	*.TOL			-         NC Tooling file
      	*.REP			-         NC Tooling file

HPGL Plot Files
      	*.PLT			-         Drill detail & fabrication / panel drawing
